# Plugin Store promo images

Marketing images for the Seclude listing on the Craft Plugin Store, in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-seclude](https://justinholt.com/plugins/craft-seclude).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `seclude-promo-N.jpg`, 1920×1080. Chrome renders at 2× and can only
write PNG, so `build.sh` downsamples and converts to JPEG in one `sips` pass and deletes the PNG.
**Promos are JPEG, never PNG** — check `out/` holds only `.jpg` before calling the deck done.

## Screenshots

`shots/` holds real captures from the plugin-testing install, not mockups:

- `shots/*.png` — the raw captures, full width
- `shots/site/` — the set the marketing page uses: `seclude-policies`, `seclude-policy` (grants and
  abilities only), `seclude-explain` (cropped to the verdict table), `seclude-assignments`,
  `seclude-index`
- `shots/deck/` — the two the slides use, captured at a 1080px viewport rather than 1600px so the
  CP's type is still legible inside a 1000px frame on a 1920px slide

They were taken with `~/Sites/plugin-shots/capture.mjs` against `seed-demo.php` plus a few extra
entries and a contributor, Jane, who holds three of the twelve. The index shot is taken *as Jane*
(`CP_USER`/`CP_PASS`), which is the only way to show the filter working.

The policy editor on the shared test install lists every section and entry type the other
plugins' fixtures have left behind, so `seclude-policy.png` is captured with everything above
"What they get" removed from the page first.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. Palette: ink
`#110e15`, accent `#6B5B7B` (the icon tile), lilac `#B9A7CC`, sand `#E3C9A8`. Jersey 20 for
display, Inter for body.

`assets/`:

- `icon.svg` — the app icon, for the cover and the footer lockup. Copy it from `../src/icon.svg`
  whenever the icon changes.
- `watermark.svg` — the folding screen alone, no tile. Its panels are large flat areas, so it sits
  at 0.012 opacity and mostly off the left edge; at 0.022 and further in it put three solid boxes
  behind every headline.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

**Seclude is free.** The cover badge says so and there is no price anywhere else in the deck. If
that ever changes, the badge is the only place in here to edit.
